## How to Share with Claude for Visual Audit

1. Navigate to the `docs/screens/` folder in your project directory.
2. Select any screenshot file (e.g. `landing_desktop_en.png`, `configurator_cinematic_desktop.png`).
3. Drag and drop the screenshot image directly into your conversation with Claude.
4. Prompt Claude: *"Review this screenshot for visual hierarchy, spacing, typography contrast, and aesthetic balance."*
